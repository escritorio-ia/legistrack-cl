# Extensión Legislación++ · Citaciones

Envía a la app las citaciones de comisiones:

- **Senado:** automáticamente cada 3 horas (y al abrir el navegador), desde la API pública que usa senado.cl.
- **Cámara:** cuando abres una semana de citaciones en camara.cl. La extensión solo lee lo que ya ves en pantalla; no navega sola ni evita controles del sitio.

## Instalar (Chrome o Edge)

1. Abre `chrome://extensions` (o `edge://extensions`).
2. Activa **Modo de desarrollador**.
3. **Cargar descomprimida** → elige esta carpeta `extension`.
4. En la extensión, **Opciones** → pega la clave `CITACIONES_IMPORT_TOKEN` → Guardar.
